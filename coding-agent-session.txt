  What the verifier does

  - Quote location: a quote must appear in its cited document, ignoring
    whitespace differences only. Anything else is dropped and recorded with a
    reason and the original claim.
  - Vitals: a BP's systolic and diastolic must both appear as numbers in the
    quote. A verified vital becomes a Reading dated from the document's date
    field, with Celsius converted by Decimal (38.0 C is exactly 100.4 F).
  - Other observations: consents, anticoagulant mentions, plans, H&P documents
    and scheduling statements each need their quotes found and their named value
    (procedure, drug, date) present.

  The four tests the plan asked for are there (verbatim, indented, fabricated,
  wrong numbers), plus one per observation type.

  Choices I made beyond the plan's wording

  Each one is stricter than "the numbers appear in the quote", and each fails
  toward a dropped fact rather than a wrong one. Say if you want any loosened.

  - Temperature unit: the unit must directly follow the value in the quote (38.0
    C, 98.2F, 97.8 °F). A reading with the wrong unit could hide a fever, so I
    check it.
  - Time: if the model gives a time, it must appear in the quote, since time
    decides which reading governs.
  - Signed consent: a yes with no signature quote is dropped.
  - Plan drug: the drug only has to be named somewhere in the cited document,
    not inside each side's quote, because a restart instruction often doesn't
    repeat the drug name.
  - Scheduling date: only numeric dates verify (03/17/2026, 2026-03-17). A
    spelled-out month would be dropped.

  One limit to know about: when a single sentence holds two readings and two
  times, the verifier cannot tell whether the model paired them correctly.
